# Latinum · Latín 4º ESO

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

App para aprender, repasar y jugar con el latín de 4º de la ESO: casos, las cinco declinaciones, adjetivos, pronombres, verbos (activa y pasiva), preposiciones, vocabulario, traducción, evolución al castellano, latinismos, mitología e historia de Roma e Hispania. Tiene test con 13 tipos de pregunta, tarjetas con repaso inteligente (lo que fallas sale más a menudo) y tres juegos (Contrarreloj, Supervivencia y Parejas). Se puede instalar en el móvil y funciona sin conexión.

Se publica con GitHub Pages: https://indalo-apps.github.io/latin/

Para sacar una versión nueva: subir el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js), y añadir sus novedades en `NOVEDADES`. Los móviles que la tengan abierta se actualizan solos, sin cortar un test ni un juego a medias.
